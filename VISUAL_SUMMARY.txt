┌─────────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                                │
└─────────────────────────────────────────────────────────────────────────────┘

  1. User searches "Chicago Fire"
     ↓
  2. Backend extracts content IDs from Movie Box HTML
     ↓
  3. For EACH ID, fetches real metadata from movieapi.gifted.co.ke
     ↓
  4. API returns actual thumbnail URLs (cover.url)
     ↓
  5. Frontend renders real movie posters
     ↓
  6. Users see recognizable artwork! 🎉
